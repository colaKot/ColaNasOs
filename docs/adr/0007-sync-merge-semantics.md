# ADR-0007 同步是 merge 语义，永不删除目标端文件

- 状态：已采纳（2026-11-01）
- 相关：[09-任务清单 SP3-12](../09-任务清单.md)、[进度与下一步 §17](../进度与下一步.md)

## 背景

「同步」在不同产品里含义不同：rsync 默认镜像（删除目标端多余文件）、云盘默认双向合并。
NAS 用户多数是把数据从旧盘搬到新盘，误删的代价远高于漏同步。

## 决策

1. `/sync/run` 只做 **merge**：复制源端新增或内容变更的文件，**不删除目标端任何文件**；
2. 两侧同名但内容不同即为「冲突」，由 `policy`（overwrite / skip / rename）决定，
   冲突逐条落库，可在 `/sync/conflicts/resolve` 指定保留源端或目标端；
3. 客户端页不提供「镜像删除」开关——能力不存在，UI 也不暗示存在；
4. 差异预览 `/sync/diff` 只读，不写盘。

## 后果

**正面**：不会因为选错目录而丢数据；冲突可追溯、可逐条裁决；预期行为与「搬数据」的心智一致。

**负面**：不能用来做「目标端与源端严格一致」的镜像备份；长期使用会累积目标端多余文件，
需要用户自行清理。

## 替代方案

- **rsync 式镜像删除**：一次误配置即删光，且没有回收站兜底，否决。
- **双向同步**：需要版本向量与冲突文件副本，复杂度高，当前只做单向 merge。
