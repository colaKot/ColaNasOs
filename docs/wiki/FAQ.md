# 常见问题

## 登录与账号

**Q：看不到某个页面的数据 / 提示 403**
所有条目都按账号 scope 授权。先确认登录的是哪个子账号（数据按 JWT `sub` 隔离），再让管理员补对应 scope（如 `photo:read`、`transfer:write`）。客户端会直接提示缺哪个 scope。

**Q：开了两步验证后登录要输 6 位码**
TOTP（RFC 6238）。密钥只在「开启 2FA」时展示一次，当场录进验证器 App；服务端加密存储，不落日志。

**Q：重启服务端后客户端被踢回登录页**
不该发生 —— JWT 密钥是持久化的（`<dataDir>/jwt.secret`）。如果真发生了，多半是数据目录变了（`COLANAS_DATA_DIR` 被改），检查客户端连的是不是同一个服务端。

**Q：客户端找不到服务端**
客户端会自动探测 `/health`（含 `"ok":true`）并尝试 `7788 / 7888 / 23788 / 8080 / 80 / 443 / 3000 / 5000`。都不行就在登录页手动填地址。**注意**：远程 NAS 的地址不会自动匹配本机回环，要手填。

## 媒体库

**Q：相册全是占位图**
服务端没找到 ffmpeg。执行 `npm run ffmpeg:fetch` 再 `npm run ffmpeg:check`。也可以直接删掉 `<dataDir>/thumbs` 整个目录，会自动重建。

**Q：扫描很慢 / 重复扫描还是慢**
扫描是增量的（按 size + mtime）。如果目录里有几十万个文件，第一次必然慢，之后只处理新增和变更。

**Q：拍摄时间不对**
优先取 EXIF，取不到依次回落到文件名日期、文件修改时间。相机时间没校准的话，建议改文件名或在客户端手动修正。

**Q：影视没识别成剧集**
库根下建「剧名」目录，文件名带 `S01E02` / `1x02` / `第3集`，扫描后自动归集；影片页只显示不属于剧集的文件。

## 播放

**Q：播放一直转圈 / 401**
播放直链带 **5 分钟令牌**，过期后回列表重新取一次即可。

**Q：跳到还没加载的位置会卡住吗**
现在的行为：**不会卡住**。目标还没转出来时，播放器会先等转码追上（最多 10 秒，右上角显示「正在转码到 xx:xx…」）；追不上就当「点了时间条」重建会话；**按键 ±30 秒追不上则干脆不跳**，保持原位置继续播并提示「这一段还在转码，已跳过本次跳转」。

画面停住超过 8 秒，客户端的看门狗会自动接管：先「续转 + 重新定位」，再不行重建会话。

**Q：为什么 AV1 拖进度条比 H.264 慢**
AV1 首片要 7.8~10.4 s（同机 H.264 约 1.8 s、H.265 约 1.1 s），转码跟不上时就会感觉到卡。想更流畅可以在播放页手动选 H.264 / H.265 档。

**Q：转码画质能自己选吗**
可以。播放页能切档位与编码，**默认编码是 H.265**（1080P / 1.8 Mbps 起），Android TV 仍保 H.264 以保兼容。手选过的档位会被记住；没选过的用户保持直连（4K 原片不会被自动压成 1080P）。

**Q：手机上播放没声音**
检查是否有别的应用占了音频焦点；客户端会向其它播放器请求让路。

**Q：锁屏 / 通知栏没有音乐控制卡片**
Android 端音乐 / 播客已改用自建 MediaStyle 前台服务，通知栏与锁屏会显示媒体卡和上一首 / 播放暂停 / 下一首；如果用的是国产 ROM，去系统设置里把 ColaNasOs 的通知权限打开。

**Q：杜比视界电视画面发灰 / 变成 HDR10**
DV 电视必须关闭隧道模式，并钉住 DV 视频轨 + AAC 音轨。MTK 等电视开隧道只拿到 HEVC 解码器、会把 DV 输出退化成 HDR10 基础层；播放器设置里关隧道即可。

**Q：混合库里同名图片和视频删一个剩一个**
同名 `foo.mp4` + `foo.jpg` 现在作一条显示、图片当封面；删除视频时同名图片会一并删除（先进回收站，可恢复）。

## 文件与传输

**Q：上传传到一半断了**
断点续传由服务端已收分片决定，重新加入队列会接着传。取消后重新加入同样能续。

**Q：路径越界**
所有路径都是「相对文件根」，`..` 越界一律 400 —— 这是设计，不是 bug。

**Q：大文件下载会不会把内存撑爆**
不会，下载走流式 + Range。

## 下载器

**Q：退出应用会不会打断做种**
不会。内核退出会先给 transmission 发 `stopped` 公告再停进程；内核热重启也不打断做种，不会被 tracker 当成换了做种位置。

**Q：可以用自己的 Transmission 吗**
可以，在设置里填外部 RPC 地址即可；不填就自动用内置的。

## 同步

**Q：同步会把目标端多余的文件删掉吗**
**不会**。同步只复制、不删除，目标端多出来的文件永远保留，避免误删。要处理冲突去「冲突」页逐条决定保留源端还是目标端。

## 终端

**Q：为什么终端里不能管道和重定向**
这是刻意的受限设计：只允许只读白名单命令，服务端用 `execFile` 直接执行（**无 shell**），参数最多 16 个、5 秒超时、输出 64 KB 截断，工作目录限制在文件根内。需要 `system:write` 权限。

## 其它

**Q：Web 端和客户端功能一样吗**
服务端内置的 Web 界面就是同一份 Flutter Web 编译产物，页面一致；但**不能读写本地目录**，因此不执行同步。

**Q：装完没有任何窗口**
正常。服务端是**托盘常驻**，在右下角托盘图标里右键可以看版本号、开关开机自启、打开 Web 界面、退出。

**Q：托盘右键第一行是干嘛的**
那是版本号（`ColaNasOs 服务端 v1.5.x`），方便确认装的是哪一版。

**Q：相册独立端能和主客户端同时装吗？更新会串包吗**
可以。相册独立端 applicationId 是 `com.colanas.photo`，与主客户端 `com.colanas.os` 不同，能并存安装。它检查更新时带 `build=photo`，服务端只回 `apk_photo`，不会串成主客户端或电视包。

**Q：相册端提示有新版本，点进去却没包**
当前 `release/update.json` 还没挂 `apk_photo`，相册端会按包身份收口，不亮无效红点；等相册包正式发版并挂上清单后即可正常更新。

**Q：安装包提示「未知发布者」**
项目没有做代码签名（自签证书不在公开信任链里）。确认文件来自官网或 GitHub Releases 并核对 SHA256 后，选择「更多信息 → 仍要运行」。

## 还是解决不了

1. **先看客户端日志**：`%APPDATA%\colanas_os_server\logs\kernel.log`，搜 `player.` / `stall` / 报错关键字，路由里带平台与会话号。
2. 再看服务端日志里的 `incoming request` 与错误码。
3. 提 Issue 时附上：版本号（客户端「关于」页 / 托盘右键）、复现步骤、相关日志片段。
