# 快速开始

> 面向第一次上手的人。全程约 15 分钟。

## 0. 先想清楚要装哪些

ColaNasOs **服务端和客户端是分开的两个包**：

| 包 | 装在哪 | 干什么 |
| --- | --- | --- |
| `ColaNasOs-Server-1.7.0-Setup.exe` | 那台**常开的 Windows 主机**（NAS 本体） | 内核 + Web 界面 + 转码 + 本地 AI 运行时 + 内置下载器 |
| `ColaNasOs-Client-1.7.0-Setup.exe` | 你**平时用的电脑** | 桌面客户端，连服务端用 |
| `ColaNasOs-Client-1.7.0-windows-x64.zip` | 同上 | 便携版，解压即用，不想装就选它 |
| `ColaNasOs-Client-1.7.0-android-arm64.apk` | 手机 / 平板 | 连服务端用 |
| `ColaNasOs-Client-1.7.0-android-arm64-tv.apk` | 电视 / 盒子 | **和手机包不是同一个包**，遥控器操作 |
| `ColaNasOs-Photo-1.7.0-android-arm64.apk` / `ColaNasOs-Photo-1.7.0-harmony-arm64.hap` | 手机 / 平板 / 鸿蒙设备 | 相册独立端，登录后直进时间轴，可与主客户端并存 |

> 相册独立端（applicationId `com.colanas.photo`）已随 v1.7.0 发版，官网下载表可获取安卓与鸿蒙安装包。

Web 端不用单独下载：服务端内置了 Web 界面，浏览器打开 `http://服务端地址:7788` 就能用。

全部产物在 [GitHub Releases](https://github.com/colaKot/ColaNasOs/releases/latest) / [GitCode Releases](https://gitcode.com/cocacola23/ColaNasOs/releases)，官网 <https://cola.gexuan.net/#download> 上有国内加速镜像。

## 1. 装服务端

1. 下载 `ColaNasOs-Server-1.7.0-Setup.exe`（约 551 MB，含 FFmpeg 与本地 AI 运行时）。
2. 安装。**安装包未做代码签名**，SmartScreen 会提示「未知发布者」——确认文件来自官网或 GitHub Releases、并核对 SHA256 之后，选「更多信息 → 仍要运行」。
3. 装完**右下角只有一个托盘图标**，没有窗口。托盘右键可以看到版本号、开机自启开关、打开 Web 界面、退出。
4. 浏览器打开 `http://127.0.0.1:7788`，用首次启动时的管理员账号登录。

> 服务端默认**只监听 127.0.0.1**。要在局域网里访问，需要你自己做反向代理或改监听地址，见[运维手册](Operations)。

### 开机自启与静默启动

托盘右键勾「开机自动启动」即可。勾上之后开机**不会弹窗口**，直接缩进托盘（靠一个标记文件 `%APPDATA%\ColaNasOs\start-hidden` 判断，不是「起来再隐藏」——那样会先闪一个空窗口）。

## 2. 建账号

首次登录后建议立刻做两件事：

1. **改掉初始管理员口令**；
2. 给家人建**子账号**，按 scope 授权（例如只给 `photo:read`、`video:read`），不要直接给 `*`。

子账号在客户端「用户」页或服务端 `/api/v1/accounts/users` 管理。敏感账号可以在「用户」页开 **两步验证（TOTP，RFC 6238）**——密钥只在开启时展示一次，当场录进验证器。

## 3. 登记媒体库

所有库都是「文件根」下的**子目录**，在对应应用里登记即可：

| 应用 | 怎么建库 | 扫完能得到什么 |
| --- | --- | --- |
| 相册 | 「相册 → 库 → 新增」，选目录 | 时间轴、那年今日、人脸聚类、足迹地图 |
| 影视 | 「影视 → 库 → 新增」，选目录 | 时长/分辨率/编码探测、剧集归集、海报、刮削 |
| 音乐 | 「音乐 → 库 → 新增」，选目录 | 曲库、专辑、歌手、歌词 |
| 文件 | 无需建库 | 直接浏览文件根，支持分片上传与 Range 下载 |

- **扫描**是增量的：按 size + mtime 比对，重复扫只处理新增和变更。
- 拍摄时间优先取 EXIF，取不到依次回落到**文件名日期 → 文件修改时间**。
- 缩略图、封面按需生成并缓存（`<dataDir>/thumbs`），整目录删掉会自动重建。

## 4. 让内容进来

三种方式，都支持：

- **上传**：客户端「传输」页 → 选目标目录 → 选文件（可多选）→ 排队。已存在且同尺寸直接秒传，失败可重传，断点续传由服务端已收分片决定。
- **内置下载器**：随包内置 transmission-daemon 与中文 Web UI，「发现 → 订阅」配置 RSS 规则即可自动下载；下载完成后文件监控会自动入库并触发刮削。
- **同步**：从 NAS、局域网机器或另一台设备按计划同步目录。**同步只复制、不删除**，目标端多出来的文件永远保留。

## 5. 连客户端

1. 装好客户端后启动，填**服务端地址**（局域网用 `http://192.168.x.x:7788`）。
2. 登录。勾了「记住我」后会自动登录；开了 2FA 的账号每次要输 6 位码。
3. 客户端会**自动发现**本机与局域网内的服务端（探测 `/health`），通常不用手填地址。

> 端口默认 **7788**。如果改了端口且服务端的端口不在默认探测列表里，就在登录页手动填。

## 6. 看视频（转码播放）

影视详情页点「转码播放」：服务端边转边播（2 秒一片），客户端同时可以干别的。几个实用点：

- 播放直链带 **5 分钟令牌**，过期后回列表重新取一次即可。
- 播放器支持快进 / 快退。**目标还没转出来时会先等转码追上**（最多 10 秒，右上角显示「正在转码到 xx:xx…」）；实在追不上就当点了时间条重建会话，**不会出现「跳了就不动」的情况**。
- 播放器画面停住超过 8 秒会自动自救（续转 + 重新定位），再不行就重建会话。
- 手机 / 平板 / TV 端与桌面端是同一套播放器逻辑。
- TV 遥控器**长按左右键**会加速拖动进度（松开才真正 seek），**上下滑**跟手切集；DV 电视若画面发灰，去播放器设置关闭隧道模式。
- 相册想单独用一个 App：装**相册独立端**（登录后直进时间轴，更多页有「关于」可查版本 / 更新 / NAS 地址），它与主客户端可并存；安卓 / 鸿蒙安装包在官网下载表获取。

## 7. 本地 AI（可选）

在「相册 → 智能相册」里可以跑人脸聚类、场景识别、语义检索；「AI 播客」能抓新闻写稿并 TTS 朗读。全部在本机推理，**图片不会上传到任何地方**。

模型随安装包分发在 `vendor/models/`，也可以在应用内按需下载翻译与 TTS 权重（约 1.4 GB）。详见[本地 AI 与模型](Local-AI)。
