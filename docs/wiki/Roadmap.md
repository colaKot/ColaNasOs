## 近期重点

1. **播放器链路**（最影响体验）：转码首片速度、AV1 首片时长、拖动与连按的边界条件、停滞自愈的覆盖面。
2. **服务端续转唤醒**：会话转完一段停手后，客户端能催转，但服务端侧的自动唤醒还应更稳。
3. **Apple TV**：官方无 Flutter 支持，当前保留 Swift 壳 + 桥接方案，待验证。
4. **多语言**：13 种语言已登记，翻译流水线就位（见 `docs/i18n/翻译工作流.md`），其余语言待人工翻译。

## 完成定义（DoD）

一份改动要算「做完」，按 `docs/10-DoD.md` 的四类 DoD 自查：

| 类型 | 要点 |
| --- | --- |
| 内核任务 | 编译 0 error；迁移可前滚可回滚；不破坏单实例与 ABI；错误码登记 |
| 域模块任务 | 端到端回归通过；对照功能覆盖台账逐项打勾；单域故障不影响其它域 |
| 客户端页面 | `flutter analyze lib` 全量 0 error；窄屏/宽屏都验；空态/错误态/加载态齐全；i18n 键齐全 |
| 文档任务 | 同步更新对应分册与 Wiki；命令可复制执行；结论有证据 |

评审清单（PR 模板）在 `docs/10-DoD.md` §5。
