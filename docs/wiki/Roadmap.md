## 主干已落地（待发版）

当前公开安装包是 **v1.5.0**，主干版本已推进到 **1.5.7**（Android buildCode 78）。以下改动已进主干，等下一个安装包分发：

| 方向 | 内容 |
| --- | --- |
| 相册独立端 | 同一工程 `main_photo.dart` 入口、`build-photo.bat` 出包，applicationId `com.colanas.photo` 与主客户端并存；登录后直进时间轴，更多页有「关于」；更新通道新增 `apk_photo` 身份 |
| 安卓三包身份 | `apk` / `apk_tv` / `apk_photo` 三者不互通，客户端检查更新分别带 `build=phone\|tv\|photo` |
| TV 播放器交互 | 遥控器长按左右 420 ms 加速拖进度（4×→180×，松开才 seek）；上下滑跟手切集（原生层平移 + 抽帧占位）；混合库播放页改「列表 + 删除当前影片」 |
| 杜比视界兼容 | DV 电视关隧道 + 钉住 DV 视频轨 / AAC 音轨，避免退化成 HDR10 基础层；`.m3u8` 按 HLS 声明、DV 失败兜底、解码诊断落日志 |
| 影视 / 图片混合库 | 同名图片作视频封面、全屏翻页、按 `coverWidth`/`coverHeight` 真实比例排版；删视频连同名图片一并删；修 SMB / UNC 路径斜杠折叠；日系榜单移到发现页 |
| 音乐 / 播客 | Android 自建 MediaStyle 前台服务（通知栏 / 锁屏媒体卡与控制）；起停与 TTS 分块淡入淡出 |

## 近期重点

1. **相册独立端正式发包**：把 `apk_photo` 接入 `release/update.json` 与官网下载表，让主干已就绪的相册端真正可下载、可更新。
2. **播放器链路**（最影响体验）：转码首片速度、AV1 首片时长、拖动与连按的边界条件、停滞自愈的覆盖面。
3. **服务端续转唤醒**：会话转完一段停手后，客户端能催转，但服务端侧的自动唤醒还应更稳。
4. **鸿蒙端**：工程骨架已就位，等 `flutter_ohos` 与主线版本对齐后出安装包。
5. **Apple TV**：官方无 Flutter 支持，当前保留 Swift 壳 + 桥接方案，待验证。
6. **多语言**：13 种语言已登记，翻译流水线就位（见 `docs/i18n/翻译工作流.md`），其余语言待人工翻译。

## 完成定义（DoD）

一份改动要算「做完」，按 `docs/10-DoD.md` 的四类 DoD 自查：

| 类型 | 要点 |
| --- | --- |
| 内核任务 | 编译 0 error；迁移可前滚可回滚；不破坏单实例与 ABI；错误码登记 |
| 域模块任务 | 端到端回归通过；对照功能覆盖台账逐项打勾；单域故障不影响其它域 |
| 客户端页面 | `flutter analyze lib` 全量 0 error；窄屏/宽屏都验；空态/错误态/加载态齐全；i18n 键齐全 |
| 文档任务 | 同步更新对应分册与 Wiki；命令可复制执行；结论有证据 |

评审清单（PR 模板）在 `docs/10-DoD.md` §5。
