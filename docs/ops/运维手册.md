# 运维手册

面向「自己部署、自己维护」的 NAS 使用者与二次开发者。架构与设计取舍看
[01-架构总览](../01-架构总览.md)、[02-服务端内核](../02-服务端内核.md)；
决策背景看 [adr/](adr/README.md)。

## 1. 运行形态

```text
Electron 主进程（窗口 / 托盘 / 自动更新）
  └── 内核进程（Fastify，默认 127.0.0.1:7788）── SQLite（dataDir/colanas.db）
        └── Sidecar（media / indexer / ai，独立子进程）
```

- 开发：`npm run dev`（tsx 直跑内核）、`npm start`（Electron + 内核）
- 门禁：`npm run verify`（38 项，约 110 s），客户端另有 `flutter analyze` / `flutter test`
- 内核单独启动：`node dist/electron/kernel-host.js`，`PORT` 与 `COLANAS_DATA_DIR` 可覆盖

## 2. 数据目录

| 内容 | 位置 |
| --- | --- |
| 根目录 | Windows `%APPDATA%\colanas_os_server`；macOS `~/Library/Application Support/colanas_os_server`；Linux `~/.config/colanas_os_server`（`COLANAS_DATA_DIR` 可覆盖） |
| 数据库 | `<dataDir>/colanas.db`（含迁移版本表，启动时自动前滚） |
| 文件根 | 由 `files` 模块的根目录配置决定，所有「相对路径」都相对它，越界一律 400 |
| 备份 | `<dataDir>/backup`（`/backup/run` 产出，含逐文件 sha256 清单） |
| 版本 | `<dataDir>/versions/D<NNN>` + `current.json` 指针 |
| 进程号 | `<dataDir>/kernel.pid`（启动写入，退出清理） |

> 用户文件与元数据**不可重建**；索引、缩略图、AI 结果可重建（重置 `gen_*` 后重扫即可）。

## 3. 健康检查与观测

| 用途 | 入口 |
| --- | --- |
| 存活 | `GET http://127.0.0.1:7788/health`（Electron 启动即加载此页做自检） |
| 资源 | `GET /api/v1/system/monitor`：CPU 两次采样、内存、磁盘 statfs、负载、运行时长 |
| 进程 | `GET /api/v1/system/processes`；`POST /api/v1/system/processes/kill`（拒绝 pid ≤ 4 与自身） |
| 客户端 | 「监控」页（`system/monitor`） |

日志：应用日志保留 30 天、审计日志 180 天；路径与文件名默认脱敏，请求日志中的 `token=`
已做脱敏（`?token=` 只对媒体直链路由生效）。

## 4. 备份与恢复

1. 客户端「安全」页 → 立即备份：填来源目录（相对文件根）+ 可选名称；
2. 备份产物为「文件副本 + sha256 清单」，恢复前**逐文件校验清单**，篡改直接 400 `corrupted`；
3. 恢复到新目录时同名文件**拒绝覆盖**（先改名或换目标目录）；
4. 升级数据库前会自动打 DB 快照；跨大版本升级建议先做一次完整备份。

加密空间（`/vault/*`）是另一条链路：scrypt 派生密钥 + AES-256-GCM，密码不落库、不落日志，
**忘记密码即无法恢复**（设计如此）。

## 5. 更新与回滚

```text
npm run pack            # 打包（需 NSIS / DMG / AppImage 环境，尚未实现）
npm run sign            # 生成 manifest 签名（ed25519，私钥不入库）
```

更新器只接受「新版本目录 + 签名匹配的 manifest」，默认禁止降级；回滚是指针切回上一版：

```text
versions/D001 ← 旧
versions/D002 ← 当前（current.json 指向）
rollback() → current.json 改回 D001
```

## 6. 常见故障

| 现象 | 原因 / 处理 |
| --- | --- |
| 启动即报 `ERR_DLOPEN_FAILED` / ABI 不匹配 | `better-sqlite3` 等原生模块未按 Electron ABI 重建：`npm run rebuild`；纯 `node` 加载 `dist/` 也会触发 |
| 影视 / 音乐无封面、探测全失败 | 未装 ffmpeg：`npm run ffmpeg:fetch` 后 `npm run ffmpeg:check`；**不要**依赖系统 PATH 上的 ffmpeg（可能是 ImageMagick 附带版，无 ffprobe） |
| 相册格子全是占位图（`/files/thumb` 返回 503） | 同上缺 ffmpeg；缩略图由 media sidecar 生成，sidecar 脚本在 `sidecars/media/main.js`。缓存目录 `<dataDir>/thumbs`，可整目录删除后自动重建 |
| rclone 类挂载一律 501 | 未安装 rclone：安装后设置 `COLANAS_RCLONE`，或让 `rclone` 进 PATH |
| 端口被占用 | 内核端口默认 7788，用 `PORT` 覆盖；客户端会提示 |
| 播放器 401 | 直链令牌 5 分钟过期：重新在列表里取一次播放地址 |
| 笔记 / 相册条目消失 | 先确认不是登录的另一个子账号（数据按 JWT `sub` 隔离） |
| 更新后打不开 | 检查 `current.json` 指针与 `versions/` 目录完整性，执行 `rollback()` |

## 7. 安全基线

- 默认只监听 `127.0.0.1`；对外暴露必须自己加反向代理与 TLS；
- 首次启动必须改掉初始管理员口令，敏感账号开启 TOTP；
- 子账号按 scope 授权（如 `photo:read`、`backup:write`），不要给无关账号 `*`；
- IP 黑名单支持精确 IP 与 IPv4 CIDR，生效于鉴权前；
- Webhook 投递带 `x-colanas-signature: sha256=<hex>`，接收方必须验签。
