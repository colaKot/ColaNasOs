## 2. 鸿蒙端（CL4-01 待落地）

蓝图 bundleName：**`com.colanas.os`**。

签名策略（用户决定，2026-10-31）：

- **临时**复用早前项目留下的证书：`%USERPROFILE%\.ohos\config\waterprofileRelease.{cer,p7b,p12}`。
- 该 p7b profile 绑定的 bundleName 属于早前项目，**因此仅 debug 可编译**；
  release 签名会因 bundleName 与 profile 不一致而失败。
- 拿到本项目 profile 后，替换 `harmony_client/build-profile.json5` 里的
  `signingConfigs.material.certpath / profile / storeFile` 与密码即可，bundleName 不用动。
- 不要直接复制任何现成的完整 ArkTS 应用：带 WebRTC 与认证业务的应用与本项目无关，
  鸿蒙壳应按 `flutter_ohos` + 最小 ArkTS 入口重建。

## 3. 改标识的注意点

1. 改 Android `namespace` 必须同步移动 `MainActivity.kt` 的目录与 `package` 语句。
2. 改 Windows `project()` / `BINARY_NAME` 后，必须删掉 `build/windows` 再构建
   （否则 CMake 缓存会报 `Unable to generate build files`）。
3. 改 Dart 包名后要 `flutter pub get`，并同步 `test/` 里的 `package:<name>/...` 引用。
4. 已发布后再改 = 数据目录/安装标识漂移，按蓝图 §13 视为破坏性变更。
