# 10 完成定义（DoD）

> 「写完」不等于「完成」。本册定义四类任务的**完成判据**，评审时逐条对照。
> 通用前置：[`05-工程与交付`](05-工程与交付.md) 的红线与 CI 门禁。

---

## 1. 内核任务 DoD

适用：`kernel/**` 下的任何子系统（路由 / DB / 队列 / 事件 / 契约 / 配置 / 守护）。

- [ ] **编译**：`npm run build` 0 error，`strict` 下无 `any`
- [ ] **单测**：新增公共方法有单测，覆盖率 ≥ 70%（该文件）
- [ ] **错误处理**：所有外部输入经 schema 校验；异常不泄漏堆栈给客户端
- [ ] **日志**：关键路径有结构化日志；路径/文件名已脱敏
- [ ] **性能**：事务 ≤ 50 ms；无同步阻塞超过 50 ms 的调用
- [ ] **契约**：涉及路由的，`/openapi.json` 已更新且 `gen.check` 通过
- [ ] **文档**：`02-服务端内核` 对应章节已同步（如行为变更）
- [ ] **回滚**：若涉及 DB 变更，迁移提供 `down`

---

## 2. 域模块任务 DoD

适用：`src/modules/<domain>/**`。

- [ ] **功能**：附录 B 该域条目**全部** ✅
- [ ] **页面**：附录 D 该域页面全部可达（客户端联调过）
- [ ] **行为用例**：`cases/<domain>/*.json` 全绿
- [ ] **权限**：匿名 / 只读 / 普通 / 管理 四角色用例通过；越权返回 403
- [ ] **错误码**：错误分支使用 `contracts/errors.json` 中的码，无裸字符串
- [ ] **分页**：列表接口一律 cursor 分页，`limit ≤ 200`
- [ ] **隔离**：停用该模块，其他模块功能不受影响
- [ ] **性能**：该域典型接口 P95 ≤ 200 ms（真库数据）
- [ ] **迁移**：表结构变更走 migration，无 `ensureColumns`
- [ ] **i18n**：新增键 13 语言齐全，占位符一致

---

## 3. 客户端页面 DoD

适用：`apps/**` 与 `packages/nas_ui/**` 的页面/组件。

- [ ] **接契约**：API 调用走生成的 `ApiClient`，无手写 url
- [ ] **状态四件套**：加载 / 空 / 错误 / 无权限 全部实现
- [ ] **响应式**：desktop / tablet / mobile 三档断点验证；TV 端 D-pad 可达
- [ ] **主题**：颜色/间距全部走 tokens，无写死色值
- [ ] **无障碍**：对比度 ≥ 4.5:1，焦点可见，图标按钮有语义标签
- [ ] **性能**：首屏 ≤ 1.5 s（桌面/移动）/ ≤ 3 s（web）；滚动 ≥ 55 fps
- [ ] **离线**：断网时有明确提示，不白屏不卡死
- [ ] **i18n**：文案全部走键，13 语言不缺
- [ ] **回归**：端能力矩阵（§64）中该端标注一致（受限项有告知）

---

## 4. 文档任务 DoD

适用：`docs/**`（含蓝图分册、ADR、施工手册、运维/用户手册）。

- [ ] **位置正确**：落在对应分册，不新增孤立文件
- [ ] **可执行**：涉及步骤的，给出**可复制运行的命令**
- [ ] **可验证**：给出判据（数字/命令输出/勾选项），不写"应该可以"
- [ ] **一致性**：交叉引用（§编号、附录）全部有效
- [ ] **版本**：版本号递增；变更记录追加一条
- [ ] **无矛盾**：与红线（§15）不冲突；若有冲突先改红线说明
- [ ] **自有实现**：代码、资源与译文均为本项目产出（§0.1）
