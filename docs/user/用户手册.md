# 用户手册

ColaNasOs 客户端（Flutter，Windows / macOS / Linux / Android / iOS / Web 同一套页面）。
窄屏是底部导航（5 个主入口 + 「更多」），宽屏是左侧导航栏；同一套逻辑，两套布局。

> 权限：所有条目按账号 scope 授权。看不到按钮或提示 403，通常是当前子账号没有该域权限
> （如 `photo:read`、`transfer:write`），找管理员加即可。

## 0. 登录

- 账号口令登录；管理员可在客户端「用户」页建子账号并分配 scope（也可直接调 `/accounts/users`）。
- 开启两步验证后，登录需要输入验证器里的 6 位码（TOTP，RFC 6238）。
- 连续失败与 IP 黑名单由服务端判定，命中会直接拒绝。

## 1. 相册

- **库**：把 `文件` 根下的某个目录登记为相册库，重复登记返回冲突，越界路径被拒绝。
- **扫描**：扫描后才有时间轴；重复扫描只处理新增 / 变更（按 size + mtime）。
- **时间轴**：按拍摄时间倒序；拍摄时间来自 EXIF，取不到时依次回落到文件名日期、文件修改时间。
- **缩略图**：格子与相册封面加载的是服务端生成的缩略图（首次访问按需生成并缓存，之后秒开）；
  点开大图时才是原图。若整屏都是占位图，说明服务端没找到 ffmpeg（见运维手册）。
- **搜索**：按路径关键词 + 时间范围；相册按用户隔离，别人看不到你的相册。
- **相册**：新建时可以给名称、简介、封面（不选就自动用第一张），还能配「自动收录」规则 ——
  按**头像** / **场景** / **日期区间**挑，命中任意一条的照片自动进册，**之后新加进来的照片也按同一套规则自动进来**。
  规则相册在列表里带一个 ✨ 角标。改规则只增不减：已经收进来的照片不会被踢出去，要移走请手动「移出相册」。
- **多选**：勾选照片后底部「加入相册」，可以直接挑一个已有相册，也可以在现场新建（新建时选中的照片会一起带进去）。
- **智能相册**：相册页右上角「智能相册」→ 场景 / 人脸两个分段；顶栏「分析 20 张」分批推进（每批耗时取决于机器）。人脸按相似度自动分组，阈值可用服务端 COLANAS_FACE_THRESHOLD 调整。

## 2. 文件

- 浏览目录、下载（支持 Range，可断点续传）。
- 上传在「传输」页：填目标目录 → 选择文件（可多选）→ 自动排队；已存在且同尺寸的文件直接秒传，失败可重试，断点续传由服务端已收分片决定（取消后重新加入会接着传）。
- 所有路径都是「相对文件根」；`..` 越界一律 400。
- 本地文件的新建目录 / 重命名 / 删除尚未实现。

## 3. 影视

- 登记库 → 扫描：探测时长 / 分辨率 / 编码 / 字幕轨，并生成首帧海报。
- 列表按标题排序，支持关键词搜索；点条目看详情，「内置播放」直接在客户端播放（media_kit），也可「复制播放地址」交给外部播放器。
- **剧集**：顶部切到「剧集」；库根下建「剧名」目录、文件名带 `S01E02` / `1x02` / `第3集`，扫描后自动归集。
  点剧进入按季分组的选集页。影片页只显示不属于剧集的文件。
- **观看进度**：详情页有「观看进度」滑杆，手动标记后按账号保存（别人看不到）；剧集页每集右侧显示已看百分比；影视首页顶部「最近在看」列出最近 6 条，点卡片直接回到剧情。
- **转码播放**：详情页「转码播放」会先转 HLS（720p，可烧录同目录外挂字幕），完成后自动打开内置播放器；耗时与片长和机器性能相关。
- 播放直链带 5 分钟令牌，过期后重新打开播放页即可重签；内置字幕轨切换与 TMDB 刮削尚未实现。

## 4. 音乐

- 登记库 → 扫描：读 tags（标题 / 艺术家 / 专辑）、时长、内嵌封面。
- 列表可按关键词、艺术家、专辑过滤；歌单自建（跨用户不可见）。
- 可复制播放直链给外部播放器；音乐页的内置播放与后台播放尚未接入（播放内核已就位，目前只有影视详情页可内置播放）。
- **歌词**：曲目详情点「歌词」查看。优先读同目录同名 `.lrc`（支持一行多时间戳与 `[offset:]` 校正），
  其次读音频里的内嵌歌词（mp3 的 USLT、flac 的 LYRICS、m4a 的 ©lyr、ogg/opus 的注释）。有时间戳时左侧显示时间，但不会自动跟着播放高亮
  （要等播放器上报进度）。

## 5. 监控

- CPU（两次采样）、内存、磁盘、负载、运行时长；进程列表可按内存排序并结束进程
  （pid ≤ 4 与内核自身不可结束）。

## 6. 同步

- 填源目录与目标目录，选冲突策略（覆盖 / 跳过 / 重命名），先「预览差异」再「开始同步」。
- **同步只复制、不删除**：目标端多出来的文件永远保留，避免误删。
- 「任务」页看历史（复制 / 跳过 / 冲突数、字节数）；「冲突」页逐条决定保留源端还是目标端。

## 7. 用户与权限

- 「子账号」页列出全部账号：scope 标签、是否开启两步验证、是否已停用（划线）；可新建（用户名 / 初始密码 / scope 逗号分隔）与启停。
- 「开启 2FA」会展示一次性密钥与 otpauth 链接：先加进验证器 App，再输入它生成的 6 位码才真正启用；关闭 2FA 立即生效。
- 「IP 黑名单」支持精确 IP 或 CIDR（如 `10.0.0.0/8`）：命中即在内核鉴权前返回 403，移除即恢复。
- 这些操作（含 IP 黑名单）统一需要 `user:read` / `user:write`；权限不足时页面会提示缺哪个 scope。
- 两步验证密钥在服务端加密存储，明文只在「开启 2FA」时展示一次，请当场录入验证器。

## 8. 终端（受限）

- 只支持只读白名单命令：`pwd` / `ls` / `dir` / `df` / `free` / `ps` / `tasklist` / `uname` / `whoami`。
- 不做管道、重定向与变量替换：服务端用 `execFile` 直接执行（无 shell），参数最多 16 个、5 秒超时、输出 64 KB 截断，工作目录限制在文件根内。
- 需要 `system:write`；想要完整交互式终端，当前版本不提供（需 PTY 原生模块）。

## 9. 常见问题

| 问题 | 说明 |
| --- | --- |
| 看不到某个页面的数据 | 检查登录的是哪个子账号（数据按账号隔离）与 scope |
| 影视 / 音乐没有封面 | 服务端未装 ffmpeg，找管理员执行 `npm run ffmpeg:fetch` |
| 播放地址打开 401 | 直链令牌 5 分钟过期，回列表重新获取 |
