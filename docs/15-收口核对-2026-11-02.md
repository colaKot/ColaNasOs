## 2. 核对出的问题（本轮已修）

### P1 `audio_normalize` 是个假开关

- 现象：`082` 迁移有列 → `library/flags` 能写 → 库设置页有「响度归一」开关，**但播放端没有任何人读它**。
  用户切了开关，什么都不会发生。
- 处理：**撤掉 UI 开关**，列与契约保留（避免破坏兼容），文档标注"播放端未接"。
- 真要接上的话，落点是：`kernel.media.hls()` 目前只透传 `preset/codec/subtitle`，
  要在 sidecar 的 ffmpeg 参数里加 `-af dynaudnorm`，再由 `routes/playback.ts` 读库上的 flag。
  这是一条完整特性，不该混在核对里做。

> 原则：界面上不摆"点了没反应"的开关。这和 Web 端不给下载假按钮是同一条。

### P2 筛选生效时，搜索词被静默丢弃

- 现象：`/photo/filter` 只吃条件、不吃关键词；而 `_loadTimeline` 在 `_filter != null` 时直接走筛选分支，
  `_query` 完全没用上。**搜索框有字、结果不跟着变**，还不报错——最坏的一种 bug。
- 处理：`FilterBody` 增 `q`（匹配 `rel_path` 与 `photo_ocr.text`），客户端传 `_query`；
  空请求守卫改为「条件与关键词都为空才返回空集」。
- 验收：`filter_q_only` / `filter_q_and_scene` / `filter_q_and_scene_miss` 三条，
  其中最后一条刻意让关键词与场景落在不同照片上，验证的是**与关系**而不是"能筛出东西"。

### P3 库列表顺序与首页段不一致

- 现象：`GET /video/libraries`（左栏来源）是 `order by created_at, name`；
  首页每库「最近添加」段用的是 `order by coalesce(sort_order,0)`。同一列，两种顺序。
- 处理：库列表统一为 `sort_order → created_at → name`。
- 仍缺：`sort_order` 没有编辑入口（契约与接口有）。要么给左栏加拖拽/上下移，要么接受"只能通过 API 调"——
  没有 UI 就不要再放一个"排序"开关，所以本轮**不加半截控件**。

### P4 日榜角标只覆盖主列表

- 现象：`withRank()` 只包了主列表三个返回点，收藏列表（`/video/favorites`）没包，
  同一个卡片在两个页面一个有角标一个没有。
- 处理：收藏列表也走 `withRank`。


### P5 收藏写入的 `on conflict` 与主键不匹配（补做 ④ 时撞出来的）

- 现象：`POST /video/favorites/set` 写的是 `on conflict (owner_id, item_id) do nothing`，
  而表的唯一约束是 `(owner_id, media_type, item_id)`。SQLite 找不到匹配约束直接报错，
  **收藏接口 500、收藏从未成功**——只是前端把它当"点过了"，没人回头查。
- 处理：子句对齐主键三列。
- 这条是补「演员作品收藏优先」时，用例先挂才发现的：`actor_works_favorite_first` 的首项一直是 Beta，
  查下去才发现收藏根本没落库。**先前的收藏相关冒烟只断言了"接口 200 不崩"，没断言"数据真的写进去了"。**

## 3. 上一节列出的缺口：本轮全部修掉

| 原缺口 | 现在的做法 |
| --- | --- |
| 库级 `sortOrder` 无入口 | 库设置页改成**可拖拽排序**（`ReorderableListView` + `onReorderItem`，拖完按索引 × 10 批量写 `sortOrder`）；库列表 SQL 也按它排，左栏 / 首页段一致 |
| 响度归一是假开关 | 打通三层：`video_libraries.audio_normalize` → `player` 转码 pump 读取 → `k.media.hls(audioFilter)` → `sidecar -af dynaudnorm`。UI 开关恢复，提示改为"转码播放时统一音量" |
| 周榜 / 月榜没有角标 | `Item` 增 `rankWeekly` / `rankMonthly`；卡片显示三者里**最好的一次**（`榜 3`），tooltip 给出「日榜 3 · 周榜 8 · 月榜 -」。三个角标塞不进海报角，所以合成一个 |
| 演员作品没有「收藏优先」 | works 排序改为「收藏 → 未看 → 最近入库」；同时修掉 P5 |
| 查看器里没有下载 | 查看器 AppBar 加下载（桌面）/ 复制链接（Web），复用 `PhotoDownload` |
| 真实联网没覆盖 | 新增 `smoke:catalog-live`：起一个**本地假 TMDB**，`baseUrl` 指过去，跑真正的 `tmdbGet` → 落库 → 降级 → `stale` 回退。不联网、能进门禁 |
