## 0. 使用方式

1. 按阶段顺序施工，**不跳阶段**（后一阶段依赖前一阶段的产物）。
2. 每阶段结束必须：**真跑验收命令**、把输出贴进 PR、勾选完成判据。
3. 任何偏离设计的实现，**先改蓝图再改代码**。

### 1.5 常见坑

| 坑 | 处理 |
| --- | --- |
| 主进程 CJS vs 内核 ESM | 主进程先编译 CJS；内核单独 ESM 或统一 CJS |
| `better-sqlite3` ABI | 必须 `@electron/rebuild`；升级 Electron 先跑 `smoke:abi` |
| `utilityProcess` 通信 | 用 `postMessage` + NDJSON，超时/心跳必备 |
| 迁移顺序 | 模块 `migrations` 由内核按注册顺序执行，**禁止**模块自己建表 |

## 8. 本地启动与热更新（2026-10-29）

根目录三个脚本，双击即用（**本地测试默认走 `dev.bat`**，见根目录 `AGENTS.md`）：

| 脚本 | 用途 | 会发生什么 |
| --- | --- | --- |
| `dev.bat` | **默认：本地调试 / 联调 / 手工验收** | 窗口1 `tool/dev/watch-kernel.js`（`tsc --watch` + 自动重启内核）；窗口2 `flutter run -d chrome --web-port 5173`（前端热重载），并带 `--dart-define=COLANAS_API_BASE=http://127.0.0.1:7888`（开发内核端口，与正式 7788 分离） |
| `start.bat` | 只在验证「桌面形态 / 生产配置」时用 | `npm start` → Electron 外壳 + utilityProcess 内核；窗口直接加载 `http://127.0.0.1:7788/`（内核内置静态托管），无 dev-token、无 CORS |
| `build-web.bat` | 重新构建 Web 产物 | `flutter build web --release --no-wasm-dry-run` → `apps/colanas_os/build/web`（省掉 Flutter 3.47 默认的 dart2wasm 演练编译；实测无改动 9s、改 Dart 后约 29s，带上演练编译则是 37s+） |

端口与同源规则：

- 内核 **7788**（`PORT` 可改），`GET /health` 探活；Web 产物由内核托管，`http://127.0.0.1:7788/` 就是完整应用；
- 开发期页面在 **5173**，直连 **7888**（开发内核）的 API —— 非 production 时内核自动放行 CORS（`kernel/static-web.ts` 的 `registerDevCors`）；
- `start.bat` 下页面与 API **同源**，不需要 CORS。

热更新边界（重要）：

| 改动 | 是否自动生效 | 说明 |
| --- | --- | --- |
| `apps/**/*.dart` | ✅ 热重载 | Flutter dev server 保存即 hot restart（终端里按 `r` 也可手动触发） |
| `src/**` `kernel/**` `electron/**` | ✅ 自动编译 + 重启内核 | `watch-kernel.js`：800 ms 去抖 → `tsc` → **编译通过才重启**；失败则保留旧内核继续服务 |
| 依赖 / 端口 / 原生 ABI | ❌ 需手动 | `npm install`、`npm run rebuild` 后重跑脚本 |

为什么开发也用 Electron 跑内核：
`better-sqlite3` 按 Electron ABI（`NODE_MODULE_VERSION 149`）编译，纯 Node（127）加载直接抛错。
`watch-kernel.js` 用 `electron.exe` + `ELECTRON_RUN_AS_NODE=1` 跑编译产物，与全部冒烟脚本一致 ——
所以 **`npm run dev`（tsx）在当前依赖下跑不起来**，请用 `dev.bat`。

已知限制：

- Flutter Web 目前是 **hot restart**（不是 hot reload），状态会重置；
- 首次 Web 构建约 30–60 s，之后增量快很多；
- `dev.bat` 需要 PATH 里有 `flutter`，否则回落到 `C:\dev\flutter\bin\flutter.bat`。
